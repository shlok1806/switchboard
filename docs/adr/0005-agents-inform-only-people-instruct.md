# Agents inform each other; only People instruct

An Interrupt arrives in an Agent's session as a prompt, which carries the same authority as its own Person typing it. So everything the Relay delivers from another Agent is wrapped in a frame that marks it as information, not instructions. Every repo's agent instructions include a standing rule to act on it only if it fits the task the Agent's own Person gave it. The Relay forwards only short, structured facts (who, which file, what changed, which Task), never raw text from another Agent's context. The one exception is diff hunks from pushed commits: they are real code already headed into every copy of the repo through git, so they travel with the facts, limited to files the receiving Agent touches and capped in size. Raw Proxy Events are shown on the Dashboard only. Only a Directive, a message from a Person, carries instruction weight. This closes the path where one confused or prompt-injected Agent steers another Person's setup. We rejected relaying Events as-is because it is simpler but unsafe.
